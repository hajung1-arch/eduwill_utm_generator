데이터 거버넌스를 위한
UTM 생성 가이드

마케팅을 몰라도 UTM 링크는 만들 수 있어요. "UTM이 뭔지도 잘 모르겠다" 싶으셔도 괜찮아요. 이 페이지를 위에서부터 순서대로 읽고 그대로 따라 하면, 누구나 5분 안에 정확한 링크를 만들 수 있도록 만들었습니다.

지금 바로 생성기 열어보기 → 읽으면서 같이 눌러보시면 더 빨리 이해돼요
01

왜 이 작업을 하나요 — 데이터 거버넌스 관점

"링크 하나 만드는데 이렇게까지 규칙이 필요한가" 싶으실 수 있어요. 근데 이건 단순히 링크를 예쁘게 정리하자는 게 아니라, 회사가 어디서 성장하고 있는지를 정확히 아는 것과 직접 연결된 문제예요.

데이터 거버넌스란

데이터 거버넌스는 어려운 말 같지만 뜻은 간단해요 — "우리 조직의 데이터를 같은 기준으로 관리해서, 누가 봐도 같은 결론을 낼 수 있게 만드는 것"이에요.

예를 들어 "이번 달 매출이 어디서 가장 많이 나왔나요?"라는 질문에 답하려면, 모든 팀이 같은 방식으로 "이 트래픽이 어디서 왔는지"를 기록해뒀어야 해요. 팀마다, 담당자마다 제각각 기록했다면 아무리 데이터를 모아봐도 정확한 답을 낼 수 없어요.

이게 왜 성장과 연결되나요

마케팅 예산과 리소스는 한정돼 있어요. "어떤 채널에 더 투자해야 매출이 느는지"를 판단하려면, 채널별 성과를 정확히 비교할 수 있어야 해요. 지금까지는 이게 불가능했어요 — 실제 데이터를 열어보면 이런 상태였거든요.

1,284
"누가 보냈나" 값이 제각각 1,284개
11,303
캠페인 이름이 제각각 11,303개
79
이제부터 쓸 표준 코드 수

같은 "네이버"인데 naver, Naver, naver_ad_pc처럼 다 다르게 적혀 있으면, "네이버에서 얼마나 왔고 얼마나 구매로 이어졌는지" 물어봐도 정확한 답을 낼 수가 없어요. 이 상태로는 어디에 예산을 더 써야 할지, 어떤 채널을 줄여야 할지 감으로 판단할 수밖에 없어요.

정리하면 UTM 규칙을 통일하는 건 "링크 정리"가 아니라 "우리가 데이터로 정확히 판단할 수 있는 회사가 되기 위한 기본 작업"이에요. 이 페이지에서 소개할 생성기는 정해진 값 중에서 고르기만 하면 되도록 만들어서, 마케팅 지식이 없어도 이 기준을 그대로 지킬 수 있게 했어요.
02

UTM이 뭔가요?

이름부터 낯설지만, 개념은 아주 간단해요. 하나씩 풀어드릴게요.

택배 송장이라고 생각해보세요

택배 상자에 보낸 사람, 배송 방법, 무슨 물건인지가 적힌 송장이 붙어있으면, 나중에 어떤 상자가 어디서 왜 왔는지 한눈에 알 수 있죠.

UTM도 똑같아요. 우리가 카카오톡·문자·카페 게시글 등으로 보내는 링크 끝에 "이 링크는 누가 보냈고, 어떤 방법으로 보냈고, 무슨 목적으로 누구에게 보낸 건지" 적어두는 꼬리표예요.

이 꼬리표가 붙어 있어야, 나중에 "이번 카카오 알림톡으로 몇 명이 들어와서 몇 명이 구매했는지"를 정확히 확인할 수 있어요. 꼬리표가 없으면 그 링크를 누가 눌렀는지 다 뒤섞여서 알 수가 없어요.

실제로 이렇게 생겼어요

꼬리표가 없는 링크 (지금까지 이렇게 많이 보내셨을 거예요) https://land.eduwill.net/sites/home
UTM 꼬리표가 붙은 링크 (앞으로 이렇게 만들 거예요) https://land.eduwill.net/sites/home?utm_source=kakao&utm_medium=alimtalk&utm_campaign=gov9_admin_basic_purchase_cartpending_260820

뒤에 붙은 ?utm_... 부분이 꼬리표예요. 사람이 보기엔 복잡해 보이지만, 이 페이지에서 소개할 생성기가 이 부분을 자동으로 만들어줘요. 우리는 몇 가지만 클릭하면 됩니다.

03

링크 하나 만드는 데 필요한 정보 5가지

생성기를 열면 이 5가지를 순서대로 물어봐요. 미리 감을 잡아두면 훨씬 쉬워요.

1

어디로 보낼 링크인가요?

고객이 최종적으로 도착할 페이지 주소예요. 흔히 "랜딩 페이지"라고 불러요.

예: https://land.eduwill.net/sites/home
2

누가 보내는 링크인가요? (소스)

이 링크를 처음 클릭하게 만든 주체예요. "네이버 검색"인지 "카카오"인지 "우리가 직접" 보내는 건지.

예: naver, kakao, eduwill
3

어떤 방법으로 보내나요? (매체)

같은 "네이버"라도 검색광고인지 블로그인지에 따라 다르고, 같은 "우리가 직접"이라도 문자인지 알림톡인지에 따라 달라요.

예: alimtalk(알림톡), search(검색광고)
4

무슨 내용을, 왜, 누구에게 보내나요? (캠페인)

강좌/상품이 뭔지, 이 링크의 목적이 뭔지(구매 유도인지 이벤트인지), 어떤 고객군에게 보내는지를 조합해서 자동으로 만들어져요. 우리는 각각 골라주기만 하면 돼요.

예: 9급공무원 강좌 + 구매 유도 + 결제 미완료 고객
5

(선택) 이 캠페인만의 별명

위 4가지 조건이 같은 캠페인을 같은 날 여러 개 보낼 때만 채우면 돼요. 보통은 비워둬도 됩니다.

예: blackfriday, d100
04

생성기 사용법 — 처음부터 끝까지 따라 하기

예시 상황을 하나 정해서, 실제로 처음부터 끝까지 만들어볼게요.
예시 상황: "9급공무원 강좌를 장바구니에 담고 결제를 안 한 고객에게, 카카오 알림톡으로 결제 유도 메시지를 보낸다"

생성기 주소 https://hajung1-arch.github.io/eduwill_utm_generator/ — 즐겨찾기에 추가해두시면 편해요.

시작하기 전에 — 화면 위쪽의 연동 상태 확인

0-1

"데이터 소스 — 구글 시트 연동"

생성기 맨 위에 이 카드가 있어요. 이건 소스·매체·목적 같은 선택 목록 전체를 구글시트에서 실시간으로 불러오는 연결이에요. 팀 공용 시트가 기본으로 이미 연결되어 있어서, 별도로 누르실 건 없어요. 그냥 이런 게 있다는 것만 알아두시면 됩니다.

혹시 드롭다운이 텅 비어있거나 이상하면 화면에 "일부 탭을 불러오지 못해 기본값으로 대체했습니다"라는 주황색 문구가 뜨는지 확인하세요. 뜬다면 인터넷 연결을 확인하고 "새로고침" 버튼을 한 번 눌러보세요. 그래도 안 되면 담당자(그로스실)에게 알려주세요.
0-2

"팀별 아카이빙 — Apps Script 웹앱 연동"

이건 "기록에 저장"을 눌렀을 때 팀 시트에 자동으로 기록을 남겨주는 연결이에요. 이것도 팀 공용 웹앱이 기본으로 이미 연결되어 있어서, 평소엔 신경 쓰지 않으셔도 됩니다. 자세한 확인·문제해결 방법은 06번 "저장(아카이빙)이란" 항목에서 다룰게요.

STEP 1 · 대상 링크

1

랜딩 URL 입력

고객이 최종적으로 도착할 페이지 주소를 그대로 붙여넣으세요. ?가 있든 없든 신경 안 쓰셔도 돼요 — 생성기가 알아서 처리해요.

입력값https://land.eduwill.net/sites/home
2

작성 팀 / 작성 담당자 (필수)

본인 소속 팀을 목록에서 고르고, 이름을 입력하세요. 이 정보는 저장할 때 "누가 언제 이 링크를 만들었는지" 기록에 남아요 — 나중에 담당자를 찾아야 할 때 요긴해요.

입력값팀: 그로스실   /   담당자: 정현아
실제 화면 — STEP 1을 다 채운 모습

STEP 2 · 소스 (누가 보냈나) 필수

3

소스 선택

이 링크를 처음 클릭하게 만든 채널을 목록에서 고르세요. 지금은 "우리가 카카오로 직접 보내는" 상황이니 kakao를 고릅니다.

선택값kakao (카카오)

STEP 3 · 매체 (어떻게 보냈나) 필수

4

매체 선택

같은 카카오라도 알림톡인지 친구톡인지에 따라 골라요. 여기선 결제 유도 안내라서 알림톡을 고릅니다.

선택값alimtalk (카카오 알림톡)

STEP 4 · 캠페인 (콘텐츠 · 목적 · 타겟 · 발송일)

5

콘텐츠 선택 (필수) — 대분류만 골라도 되고, 더 자세히 골라도 돼요

대분류를 먼저 고르면, 중분류 목록이 그 대분류에 속한 것들로만 좁혀져요. 소분류까지 고르면 더 구체적으로 표현할 수 있어요. 중분류·소분류는 선택 사항이라 건너뛰어도 됩니다.

대분류gov (공무원&입시)
중분류선택 안 함 — 더 구체적으로 표현하고 싶을 때만 채우면 돼요
소분류선택 안 함
실제 화면 — STEP 4를 다 채운 모습 (중분류·소분류는 선택 안 함으로 남겨둔 예시)
6

캠페인 목적 선택 (필수)

이 링크를 왜 보내는지예요. 결제 유도가 목적이니 "구매"를 고릅니다.

선택값purchase (행동_구매)
7

타겟 세그먼트 선택 (필수)

누구에게 보내는지예요. 장바구니 담고 결제 안 한 사람들이니 "구매전환대기"를 고릅니다.

선택값cartpending (구매전환대기)
8

발송일 선택 (필수)

오늘 날짜가 기본으로 들어가 있어요. 실제로 발송하는 날짜로 맞춰주세요.

선택값2026-08-20
9

캠페인 세부명 (선택 — 대부분 비워둬도 됨)

같은 날, 같은 콘텐츠·목적·타겟으로 캠페인이 두 개 이상 나갈 때만 채우세요. 예를 들어 오늘 "구매전환대기" 대상으로 알림톡을 하나 더 보낸다면, 서로 구분하기 위해 여기에 별명을 붙여요. 지금 예시는 하나뿐이니 "선택 안 함"으로 둡니다. (자세한 목록은 09. 전체 코드표에서 확인할 수 있어요.)

10

완성! 오른쪽에서 링크 확인 → 복사

여기까지 채우면 오른쪽 "캠페인 코드 미리보기"에 조각들이 조립되는 게 보이고, 그 아래 "생성된 URL"에 완성된 링크가 자동으로 나타나요.

화면 오른쪽 위 — 캠페인 코드가 조각조각 조립되는 모습이 바로 보여요
화면 오른쪽 아래 — 완성된 링크와 "URL 복사" · "기록에 저장" 버튼

URL 복사 버튼을 누르면 바로 사용할 수 있어요.

완성된 링크https://land.eduwill.net/sites/home?utm_source=kakao&utm_medium=alimtalk&utm_campaign=gov_purchase_cartpending_260820
"기록에 저장"은 꼭 눌러주세요 링크를 다 썼다고 끝이 아니에요. "기록에 저장"을 눌러야 팀 시트에 자동으로 기록이 남아요. 나중에 "저 링크 언제 누가 만들었지?"를 찾을 때 이 기록이 유일한 단서가 돼요. (자세한 내용은 06번 항목 참고)
05

"직접 입력"이 뭔가요?

목록에 원하는 값이 없을 때 쓰는 기능이에요. 언제, 어떻게 쓰는지 정확히 알려드릴게요.

언제 쓰나요

드롭다운(선택 목록)을 눌렀는데 내가 찾는 값이 안 보일 때만 씁니다. 예를 들어 아직 코드북에 등록 안 된 신규 강좌라던가, 아직 목록에 없는 담당자 이름 같은 경우예요.

목록에 이미 있는 값이면 절대 직접 입력하지 마세요. 같은 뜻이라도 사람마다 다르게 타이핑하면 (예: Naver vs naver) 데이터가 또 흩어져버려서, 지금까지 정리한 게 다시 엉망이 돼요.

사용 방법 (아이템/콘텐츠·팀·세부명 공통)

1

드롭다운 클릭 → 목록 맨 아래 "직접 입력…" 선택

드롭다운을 열면 실제 항목들 아래에 직접 입력…이라는 항목이 있어요. 그걸 클릭하세요.

2

바로 아래 나타나는 입력창에 타이핑

"직접 입력…"을 선택하면 그 아래에 빈 텍스트 칸이 새로 나타나요. 거기에 원하는 값을 입력하면 됩니다.

"직접 입력…"을 고르면 바로 아래에 텍스트 칸이 나타나요 (여기선 "spec"이라고 입력한 예시)
작성 담당자는 조금 달라요 담당자 입력창은 처음부터 그냥 텍스트 칸이에요. "직접 입력" 선택 없이 바로 이름을 타이핑하면 되고, 타이핑하는 동안 목록에 있는 이름이면 자동으로 후보가 떠요.

06

저장(아카이빙)이란 무엇인가요

링크를 만들고 나면 꼭 "기록에 저장"을 눌러주세요. 왜 필요한지, 어떻게 동작하는지, 안 될 때는 어떻게 하는지 설명드릴게요.

왜 저장해야 하나요

링크를 만들어서 바로 복사해 쓰고 끝내면, 나중에 그 링크를 누가 언제 왜 만들었는지 아무도 알 수 없어요. "기록에 저장"을 누르면 팀 이름의 구글시트 탭에 자동으로 한 줄씩 기록이 쌓여요 — 저장일시, 담당자, 랜딩 URL, 목적, 타겟 등 모든 정보가 함께요.

이래서 작성 팀 · 작성 담당자가 필수예요

이 두 정보가 있어야 "이 링크는 그로스실 정현아가 만들었다"는 게 기록에 남아요. 비워두면 나중에 문제가 생겼을 때(예: 잘못된 링크가 발견됐을 때) 누구에게 물어봐야 할지조차 알 수 없게 돼요. 그래서 필수값으로 막아뒀어요 — 비워두면 링크 생성 버튼이 눌리지 않습니다.

"팀별 아카이빙 — Apps Script 웹앱 연동" 자세히 보기

생성기 맨 위에 있는 이 카드가 저장 기능을 담당해요. 팀 공용 웹앱이 기본으로 이미 연결되어 있어서, 평소엔 이 카드를 건드릴 일이 없어요. "기록에 저장"만 누르면 자동으로 팀 시트에 기록됩니다.

✓

정상 작동 확인하는 법

"기록에 저장"을 눌렀을 때 화면에 저장됨 · [팀 이름] 시트로 전송 중이라는 문구가 뜨면 정상이에요. 이 브라우저에 저장됨 (팀 시트 연동 안 됨)이라는 문구가 뜬다면 아래 해결 방법을 확인해주세요.

연결이 안 되어 있을 때 해결 방법
1단계. 상단 "팀별 아카이빙" 입력창에 URL이 채워져 있는지 확인하세요. 비어있다면 담당자(그로스실)에게 연결 URL을 다시 받아서 붙여넣고 "연결 저장"을 눌러주세요.
2단계. URL은 있는데도 안 된다면, "기본값으로 되돌리기"를 눌러 팀 공용 웹앱으로 재연결해보세요.
3단계. 그래도 안 되면 이건 담당자가 확인해야 하는 문제예요(구글시트 쪽 권한 설정 문제일 가능성이 높아요) — "기록에 저장을 눌렀는데 시트에 안 쌓여요"라고 담당자(그로스실)에게 알려주세요.

참고로 이 연결이 안 되어 있어도 링크 생성 자체는 정상적으로 됩니다 — 다만 "기록에 저장"을 눌렀을 때 내 브라우저에만 기록이 남고, 팀 공용 시트에는 안 쌓인다는 차이만 있어요. 그래도 팀 전체 기록을 위해서는 꼭 연결된 상태로 사용해주세요.

자주 묻는 질문

UTM을 안 붙이면 어떻게 되나요?
링크는 정상적으로 작동해서 페이지 이동에는 문제없어요. 다만 GA4(구글 애널리틱스)에서 "이 방문자가 어디서 왔는지"를 알 수 없게 돼요. 이 캠페인의 성과(몇 명이 클릭해서 몇 명이 구매했는지)를 전혀 확인할 수 없다는 뜻이에요.
목록에 필요한 값이 없으면 어떻게 하나요?
"직접 입력…"으로 일단 사용하시고, 앞으로도 계속 쓸 값이면 팀에 코드북(구글시트) 추가를 요청해주세요.
실수로 잘못된 값을 저장했어요. 지울 수 있나요?
생성기 화면 아래 "생성 기록"에서 해당 항목의 "삭제"를 누르면 이 브라우저 기록뿐 아니라 팀 시트의 해당 행도 함께 지워져요.
대분류만 고르고 중분류·소분류는 안 골라도 되나요?
네, 됩니다. 대분류만 필수이고 중분류·소분류는 선택 사항이에요. 더 구체적으로 구분하고 싶을 때만 채우면 돼요.
같은 링크를 여러 번 만들면 안 되나요?
조건(콘텐츠·목적·타겟·발송일)이 같은 캠페인을 정말 여러 개 보내야 한다면, "캠페인 세부명"으로 구분해주세요. 그렇지 않다면 이미 만든 링크를 재사용하시면 됩니다.
